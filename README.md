## Scan Kenya
> Scan products, see information and get their prices.

## How it works
1. Uses the [Barcode Detection API](https://developer.mozilla.org/en-US/docs/Web/API/Barcode_Detection_API) to scan products and get the GTIN. 
2. It then uses the GTIN to fetch the product information (WIP 🚧)
3. You can then check the prices accross supermarkets in Kenya (WIP 🚧)
